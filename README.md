# The Ball Room — Pickleball Platform

Court booking platform for pickleball.

## Project Structure

```text
Squash/
├── frontend/               # React + Vite frontend application
│   ├── src/                # UI components, pages, animations
│   ├── public/             # Static assets
│   ├── package.json
│   └── vite.config.js
├── backend/                # Express + Prisma REST API server
│   ├── src/                # Routes, middleware, controllers, prisma models
│   ├── prisma.config.ts
│   ├── package.json
│   └── tsconfig.json
├── docs/                   # Documentation and guides
├── scripts/                # Utility scripts
└── BACKEND_PLAN.md         # Backend implementation plan
```

## Getting Started

### 1. Frontend

```bash
cd frontend
npm install
npm run dev
```

### 2. Backend

```bash
cd backend
npm install
npm run dev
```
